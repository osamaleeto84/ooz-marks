# Ooz Marks — الخادم (Vercel + Neon)

## الرفع
1. مستودع جديد على GitHub (مثلاً `Ooz-marks`) وارفع: `package.json` و `vercel.json` و `README.md` ومجلد `api` بملفاته الثلاثة (`_db.js` و `_http.js` و `api.js`).
2. مشروع جديد على Neon، وانسخ رابط الاتصال (Connection string).
3. على Vercel: Add New → Project → اختر المستودع، وقبل Deploy أضف في Environment Variables:
   - `DATABASE_URL` = رابط Neon
   - `LICENCE_SECRET` = نص سري طويل (16 حرفاً فأكثر) — احفظه ولا تغيّره، فالمفاتيح تُبنى عليه
   - `OWNER_KEY` = كلمة سر المالك (12 حرفاً فأكثر)
4. Deploy. افتح الرابط: يجب أن يظهر `{"app":"Ooz Marks API","ok":true}`.

الجداول تُنشأ تلقائياً عند أول طلب.

## التطبيق
- الرابط الافتراضي في التطبيق `https://ooz-marks.vercel.app`. إن اختلف رابطك اضغط زر «الخادم» في شاشة الدخول وضع رابطك.
- «مدرسة جديدة» يسجّل المدرسة ويعطي رمز المدرسة. المعلمون يدخلون برمز المدرسة واسم المستخدم وكلمة المرور المؤقتة.
- أدوات المالك (المدارس وإصدار مفاتيح الترخيص): اضغط سطر «تصميم م. أسامة أبو الحسن» في شاشة الدخول خمس مرات، وأدخل الرابط و `OWNER_KEY`.

لا تضع `LICENCE_SECRET` ولا `OWNER_KEY` ولا رابط Neon في أي ملف داخل المستودع.
